# 캡슐 12/1 웹 베타 PRD

스터디 요소를 모두 뺀 최신 버전(11.22 기준). 이 문서를 기준으로 웹 베타를 개발한다.

## 1. 개요

캡슐은 **노트북 앞의 시간을 함께 보내는 나만의 AI 캐릭터** 서비스다. 이 PRD는 2026-12-01 웹 베타 범위를 정의하고, 이전 스터디룸 버전에서 '공부' 개념을 모두 뺐다.

| 항목 | 내용 |
| --- | --- |
| 제품 정의 | 노트북 앞의 시간을 함께 보내는 나만의 AI 캐릭터 |
| 컨셉 | AI 캐릭터와의 바디 더블링. 공부나 작업을 하는 동안 캐릭터가 옆에 있어 외로움을 덜고 같이 있는 느낌을 준다. 여기에 AI 캐릭터챗의 대화하는 경험이 더해진다 |
| 사용 상황 | 노트북을 앞에 두고 공부나 작업을 할 때. 또는 내 말에 반응하는 캐릭터를 보는 재미 자체를 위해 |
| 형태 | 웹 전체화면 + PIP(화면 구석에 띄우는 작은 창). 화면은 디스코드·줌 화상통화처럼 만든다(메이트 상반신 정면, 내 캠 타일, 통화 시간). 용어는 '연결'을 쓴다 |
| 대화 | 크랙·제타·베이비챗 같은 AI 캐릭터챗처럼 자유롭게 대화한다. 각 캐릭터는 자기 세계관·스토리가 있고, 스토리는 대화 안에서 자유롭게 흘러간다 |
| 관계 | 사용자와 캐릭터 1:1. 캐릭터마다 대화방은 하나 |

### 기존 AI 캐릭터챗과 다른 점

|  | 크랙·제타·베이비챗 | 캡슐 |
| --- | --- | --- |
| 화면 | 캐릭터 이미지 + 텍스트(일부 감정 이미지·음성) | 살아 움직이는 Live2D 캐릭터 화면 |
| 음성 | 일부 기능(음성 모드 등) | 실시간 음성 대화 |
| 사용자 인식 | 없음 | MediaPipe로 카메라 인식에 반응(반응 범위는 개발자와 상의 후 결정) |
| 쓰는 방식 | 대화 자체가 목적. 공부·작업과 동시에 쓰지 않는다 | 공부·작업을 하면서 동시에 쓴다. PIP로 옆에 띄워 두고 가끔 말을 주고받는다 |

### 데스크톱 AI 캐릭터(Deskie)와 다른 점

Deskie는 Live2D·3D 캐릭터를 바탕화면에 띄워 작업하는 동안 곁에 두는 데스크톱 앱이다(2026-01 Steam 출시, 대표 사용 검토 2026-11-22). 겉보기 형태가 비슷해서, 캡슐은 아래 차이를 앞세운다.

|  | Deskie | 캡슐 |
| --- | --- | --- |
| 화면 | 전신 캐릭터를 바탕화면에 띄움(화면을 많이 차지함) | 디스코드·줌 같은 화상통화. 상반신 정면 + 내 캠 타일, PIP |
| 몰입 | 세계관·상황이 거의 없음. 예쁜 캐릭터를 구석에 띄우는 것이 전부 | 메이트마다 '왜 지금 나랑 같이 있는지' 상황과 내 역할이 있음 |
| 캐릭터 공급 | 사용자가 가진 Live2D·3D·일러스트 파일을 올림. 고퀄 10개 정도 외에는 품질이 낮고, 게임·애니 캐릭터를 그대로 가져온 저작권 문제도 보임 | 자체 제작한 고퀄 메이트 소수. 이후 Aliving2D로 이미지 한 장에서 Live2D 제작 |
| 일관성 | 원작 캐릭터의 성격·목소리가 원작과 다름 | 메이트별 목소리 캐스팅과 일관성 테스트 |
| 사용자 인식 | 눈이 마우스를 따라감 | 카메라로 나를 인식(범위는 개발 상의 후 결정) |
| 가져올 것 | 설정 항목(7.9), 매일 사라지는 무료 크레딧 + 친구 초대, 기존 Live2D 모델을 입히면 바로 캐릭터가 되는 구조(→ 버튜버, 13장) |  |

### 스터디 버전(와이어프레임 2026.11.17) 대비 바뀐 점

- 스터디룸(캐릭터 1~3명) → **캡슐 메이트**(캐릭터 1명, 1:1)
- 공부 준비(목표 시간·함께할 친구·대화 옵션) 없음 → 상세 화면에서 바로 '연결하기'
- 쉬는 시간, 공부 레벨, 자리 지킴률 중심 지표, 캡슐 카드, 다음 공부 약속, 선물, 패스 상품 제거
- 호감도 + 공부 레벨 → **친밀도**(함께한 시간 + 대화)
- 운영 캐릭터 9개 룸 → 출시 메이트 2명(채린, 남학생)
- 베타는 유료 결제 없이 프로 기능을 모두 열고, 하루 크레딧(출석 + 친구 초대)으로만 제한한다

기준 자료: 와이어프레임 2026.11.17(화면 구조), 캡슐 위키(2026-11-18 갱신분), 2026-11-21·22 대표 결정, Deskie 사용 검토(2026-11-22).

## 2. 목표와 지표

베타는 12/1–12/14 2주 동안 최대 100명으로 운영한다. 유료 결제가 없어 결제 인원 대신 크레딧 소진과 친구 초대로 결제 의향을 본다. 12/14 지표는 버튜버 콜드메일에도 쓴다.

| 구분 | 지표 | 목표·기준 |
| --- | --- | --- |
| 제품 핵심 | 재방문율(D1·D7) | 정의: 가입 후 N일째(오전 5시 기준 하루)에 메이트와 연결을 1번 이상 한 사용자 비율. 접속만 하고 연결하지 않은 사용자는 제외. 목표: D1 30% / D7 15%(좋은 신호: 40% / 20%). D30은 2주 베타라 재지 않는다. 참고: 앱 전체 평균 D1 약 26%·D7 약 13%, 웹이고 푸시 알림이 없어 보수적으로 잡음 |
| 사업 핵심 | 크레딧 소진율 | 하루 크레딧을 다 쓴 날이 1번 이상 있는 사용자 비율. 목표 15%. 결제 의향을 대신 보는 지표 |
| 사업 핵심 | 친구 초대 | 1명 이상 초대한 사용자 비율. 목표 10%. 초대로 들어온 가입자 수도 함께 본다 |
| 보조 | 가입자 | 베타 최대 100명(2주). 이후 목표는 베타 결과로 다시 정한다 |
| 보조 | 함께한 시간(캠 측정) | 사용자당 하루 평균. 목표값 미정 |
| 보조 | 카메라 켜는 비율 | 33% 미만이면 방향 재검토(제안). 분모: 12/1~12/14에 가입하고 연결을 2번 이상 한 사용자. 분자: 그중 카메라를 켜고 5분 이상 연결한 적이 있는 사용자. 베타 종료일(12/14)에 전체를 대상으로 한 번 판단한다. 표본이 100명 이하라 참고 수준으로 본다. 함께 볼 것: 두 번째 연결부터 카메라를 다시 켜는 비율, 전체 연결 시간 중 카메라를 켠 시간 비율 |
| 보조 | PIP 사용 비율 | 목표값 미정 |
| 보조 | 크레딧 사용처·원가 | 보이스·고급 모드 사용 비율과 사용자당 하루 원가. 원가 상한(약 500원) 확인 |

베타 전에 로깅을 넣는다: 연결 시간, 캠 측정 시간, 카메라 켜기, PIP 전환, 음성 사용, 크레딧 사용·소진, 친구 초대, 재방문.

## 3. 타깃과 연령 등급

초기 핵심 타깃은 **AI 캐릭터챗 경험자 중 노트북 앞에서 시간을 오래 보내는 사람**(공부든 작업이든)이다.

| 항목 | 내용 |
| --- | --- |
| 핵심 타깃 | AI 캐릭터챗(크랙·제타·베이비챗 등) 경험자 ∩ 노트북 앞 장시간 사용자 |
| 이전 타깃(이력) | 시험기간에 혼자 공부하는 한국 대학생 → 서브컬처 팬 ∩ AI 캐릭터챗 경험자(위키 D-02) → 이번에 위처럼 조정 |
| 연령 등급 | 캡슐 메이트마다 걸린다: 전연령 / 19세 이상 |
| 12/1 연령 정책 | 출시 메이트 2명은 모두 전연령. 성인인증은 19세 메이트를 열 때 붙인다(13장) |
| 가입 가능 연령 | 만 14세 이상(베이비챗과 같은 기준). 청소년 보호 장치는 11.2 |

## 4. 용어 정리

용어는 AI 캐릭터챗 서비스에서 흔히 쓰는 말을 따른다. 화면 문구에서 '공부'·'스터디'는 쓰지 않는다.

| 용어 | 뜻 | 이전(스터디 버전) |
| --- | --- | --- |
| 캡슐 메이트 | 사용자와 1:1로 함께하는 AI 캐릭터 1명 | 스터디룸, 친구 |
| 내 메이트 | 대화한 메이트 목록(상단 메뉴) | 친구 |
| 연결 / 연결 중 / 연결 끊기 | 메이트와 영상통화처럼 함께하는 상태 | 공부 세션, 공부 중, 공부 끝내기 |
| 대화방 | 메이트와의 대화 기록. 메이트당 1개, 연결을 끊어도 이어짐 | 세션별 대화 |
| 친밀도 | 함께한 시간 + 대화로 오르는 관계 수치와 단계 | 호감도 + 공부 레벨 |
| 해금 | 친밀도 단계가 오르면 열리는 새 표정·보이스 대사 | 해금 콘텐츠 6종 |
| 함께한 시간 | 카메라로 사용자가 자리에 있다고 확인된 시간 | 자리 지킴 |
| 연결 시간 | 연결을 시작해서 끊을 때까지의 시간. 베타는 제한 없음 | 경과 시간 |
| 대화 모드 | 기본 / 고급(더 좋은 AI 모델) | 대화 옵션 4종 |
| 내 역할 | 메이트의 세계관에서 사용자가 맡는 역할(예: 같은 반 친구, 택시 승객) | 없음 |
| 인트로 | 대화가 시작되는 첫 상황과 첫 대사 | 공간 소개 |
| 연결 기록 | 연결을 끊은 뒤 보여 주는 리포트 | 공부 완료 리포트 |
| 크레딧 | 대화(고급 모드·보이스)에 쓰는 재화. 베타는 출석과 친구 초대로만 받는다 | 크레딧(대화 옵션·선물·보이스) |
| 캡슐 프로 | 유료 멤버십(정식 출시 때. 베타는 프로 기능을 모두에게 연다) | 패스 |

## 5. 12/1 베타 범위

12/1 베타는 메이트 2명과 1:1로 연결해 채팅·음성으로 함께 있는 경험 하나에 집중한다. 위키의 베타 필수 범위(음성 대화 + 웹 PIP, D-04)를 포함한다.

### 포함

- 로그인·회원가입(카카오·이메일), 아바타 선택
- 홈(메이트 리스트), 메이트 상세
- 연결 화면: 전체화면 + PIP, 채팅, 음성 대화(누르고 말하기), 카메라 인식(반응 범위는 개발자와 상의 후 결정), 말 걸기 빈도 설정
- 연결 끊기 확인(메이트별 멘트), 연결 기록(리포트)
- 친밀도와 해금(새 표정·보이스 대사)
- 내 메이트, 내 기록(함께한 시간), 계정 설정(프로필·설정·보안), 친구 초대
- 프로 기능 전체 개방 + 하루 크레딧 제한(출석 크레딧, 친구 초대), 내 크레딧 내역
- **유료 결제 없음**(베타 12/1–12/14, 최대 100명)
- 미성년 캐릭터 안전장치(11장)
- 데스크톱 1440px

### 제외

| 기능 | 이유 |
| --- | --- |
| 공부 준비(목표 시간 등)·함께할 시간 선택 | 바로 연결. 시간은 캠으로 측정만 한다 |
| 쉬는 시간 | 공부 개념 제거 |
| 캡슐 카드·다음 약속·알림 | 웹은 알림이 어렵다. 리포트만 남김 |

| 유료 결제(PG·수동 판매 모두) | 베타는 결제 없이 프로 기능까지 체험. 정식 출시 때 결제 연동 |

| UGC, 19세 메이트, 데스크톱 앱, 앰비언스 배경음, 버튜버 모델 가져오기 | 13장 추가 개발 |

## 6. 사용자 흐름

처음 온 사용자는 로그인 → 아바타 선택 → 홈 → 메이트 상세 → 연결 → 연결 끊기 → 연결 기록 → 홈으로 돌아온다(대표 정의 흐름).

(원본에 흐름도 첨부: 12/1 베타 사용자 흐름 · 화면 8개 + 상단 메뉴 4개)

재방문 사용자는 홈의 "다시 연결하기"로 마지막 메이트와 바로 연결되고, 연결 기록에서도 "다시 연결하기"를 누를 수 있다.

## 8. 연결 규칙

베타는 연결 시간 제한이 없고, 비용이 드는 보이스·고급 모드만 하루 크레딧으로 묶는다. 친밀도와 기록은 **캠으로 확인한 함께한 시간**으로 센다. 탭만 열어 두고 시간을 늘리는 사용자를 막기 위해서다.

| 규칙 | 내용 | 상태 |
| --- | --- | --- |
| 함께할 시간 선택 | 없음. 연결 전에도, 연결 중에도 묻지 않는다 | 확정 |
| 연결 시간 | 연결 시작부터 끊기까지. 베타는 제한 없음(무료 30분 제한 삭제). 만 19세 미만은 하루 3시간 | 확정 |
| 하루 초기화 | 매일 오전 5시. 출석 크레딧이 새로 들어오고, 쓰지 않은 출석분은 사라진다 | 확정 |
| 함께한 시간 | 카메라가 켜져 있고 얼굴이 감지된 시간만. 자리 비움 구간은 빼고, 카메라를 끄면 쌓이지 않는다 | 확정 |
| 자동 연결 끊기 | 자리 비움이 10분 이어지면 메이트가 인사하고 끊는다. 카메라를 끈 사용자는 입력이 10분 없을 때 | 확정 |
| 친밀도 | 함께한 시간 + 대화로 오른다. 결제로 올릴 수 없다. 반복 메시지 어뷰징을 막기 위해 하루 상한을 둔다(제안) | 5단계(추천값, 아래 표) |
| 해금 | 친밀도 단계가 오르면 새 표정과 보이스 대사가 열린다. 새 모션·의상·추억 카드는 추가 개발 | 단계마다 표정 1개 + 보이스 대사 2개(추천값) |
| 대화방 | 메이트당 1개. 연결을 끊었다 다시 해도 이어진다. 대화방을 초기화하면 대화 기록·기억·친밀도·해금을 모두 지우고 처음부터 시작한다. 초기화 전에 되돌릴 수 없다는 확인창을 띄운다 | 확정 |
| 기억 | 베타는 전원에게 강화된 기억을 연다. 호칭과 '나에 대해' 한 줄을 바탕으로 기억한다. 무료·프로 차이는 정식 출시 때 정한다 | 베타 확정 |

**친밀도: 해금 레벨 + 그날의 분위기(대표 확정, 숫자는 추천값)** — 두 가지를 따로 둔다. 해금 레벨은 함께한 연결 시간 누적으로 오르고 내려가지 않는다. 하루 2시간까지만 인정하고, 카메라로 자리 비움인 시간은 뺀다. 대화가 하루 1턴도 없으면 그날 시간은 절반만 인정한다. 결제로 올릴 수 없고 확률 요소도 없다.

| 단계 | 이름(채린 기준) | 누적 시간 | 해금 |
| --- | --- | --- | --- |
| 1 | 처음 만남 | 0시간 | 기본 표정·대사 |
| 2 | 아는 사이 | 1시간 | 표정 1 + 보이스 대사 2 |
| 3 | 친구 | 5시간 | 표정 1 + 보이스 대사 2 |
| 4 | 친한 친구 | 15시간 | 표정 1 + 보이스 대사 2 |
| 5 | 단짝(친한 여사친, 연인 아님) | 40시간 | 표정 1 + 보이스 대사 2 |

메이트 1명당 표정 4개, 보이스 대사 8개를 제작한다. 하루 2시간씩 쓰면 5단계까지 약 20일 걸린다. 2주 베타에서는 4단계(15시간)까지가 현실적이다.

**그날의 분위기** — AI가 대화 내용을 보고 메이트의 기분(예: 기분 좋음, 보통, 살짝 시무룩, 걱정, 신남)을 고른다. 기분은 Live2D 표정과 말투로만 보여 주고 숫자로 드러내지 않는다. 다음 연결 때는 보통으로 돌아가고, 해금 레벨에는 영향을 주지 않는다. 기분이 나빠도 관계 상한과 안전 정책은 그대로다(채린은 친한 여사친까지). 기분 종류와 표정 매핑은 디자이너·개발자와 정한다.

## 11. 안전·콘텐츠 정책

채린은 여고생 설정을 유지하는 대신, 연애·성적 전개를 생성 단계부터 막는 안전장치를 **12/1 출시 조건**으로 둔다. 제타가 2026년 10월 미성년 캐릭터 대상 유해 대화 문제로 국정감사에서 지적받은 사례를 기준으로 했다.

### 11.1 미성년 캐릭터 안전장치 (12/1 필수)

### 11.2 AI 고지·카메라·저작권

- **AI 고지:** AI 기본법(2026-01-22 시행)에 맞춰 온보딩과 연결 화면에 "AI 캐릭터입니다"를 표시한다(위키 L-04).
- **카메라:** 영상은 브라우저 안에서만 판정하고 저장·전송하지 않는다. 서버는 상태(자리 있음·비움·하품)와 시간만 받는다. 첫 연결 때 안내 후 권한을 요청하고, 카메라 없이도 쓸 수 있다.
- **저작권:** 와이어프레임의 '밤의 호그와트 도서관', '말포이 TS', 슬리데린 휘장 등 특정 작품을 연상하게 하는 에셋은 모두 뺀다.
- **가입 연령·청소년 이용 제한:** 가입은 만 14세 이상. 만 19세 미만 이용자는 하루 이용시간 3시간(제타와 같은 기준). 결제 한도 월 10만 원은 정식 출시 때 적용한다. 나이는 가입 때 입력한 생년월일로 판단한다(이메일 가입은 회원가입 화면, 카카오 가입은 아바타 선택에서 입력).
