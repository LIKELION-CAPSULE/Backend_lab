# 0008 명세 원본은 노션, 레포에는 스냅샷

> **2026-11-04 대체됨 → [0013](0013-spec-source-git.md)**: 원본은 레포 `docs/specs/`, 노션은 읽기 전용 사본. 아래는 그 전의 결정이다.

- 결정: API 명세(시연 API 최종본 DB)와 DB 스키마(DB 페이지)의 원본은 노션. spec-sync 스킬이 Notion MCP로 읽어 docs/specs/api.md, schema.sql로 옮기고 PR로 커밋한다.
- 이유: 기획은 노션에서 쓰고 고치는 게 편하다. 하지만 두 사람의 에이전트, CI, 리뷰어가 같은 버전을 봐야 하고, 명세가 바뀐 내용이 PR diff로 보여야 한다. CI는 노션을 읽을 수 없다.
- 버린 대안: 에이전트가 작업마다 노션을 직접 읽기(사람·시점마다 다른 버전, CI 불가), 레포에서 명세 작성(기획 작업 흐름과 안 맞음).
- 규칙: 스냅샷은 직접 고치지 않는다. 노션 → spec-sync → 작은 명세 PR을 기능 PR보다 먼저 머지.
